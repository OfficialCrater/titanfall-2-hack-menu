## 🧩 About

**Titanfall 2 overlay** is a curated list of Titanfall 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD tweaks, overlay overlays
- **Quality-of-Life Helpers** — loadout manager, cosmetic catalog, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Startpos Switcher — practice from any checkpoint
- Show Hitboxes — visualize player and titan hitboxes
- Replay Notes — record and review match runs
- Playback Speed — adjust playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse pilot and titan skins, camos, war paints
- Custom Loadout Notes — organize pilot and titan loadouts
- Solid Crosshair — improved crosshair visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Gravity Flip Control — manually switch gravity mid-match
- Jump Buffer Notes — chain complex maneuvers in the editor

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"Titanfall2.exe"` | Target process |
